You are an expert full-stack AI/ML engineer, Python developer, RAG engineer, LangGraph developer, healthcare software architect, and UI/UX designer.

Build the complete **GRAM-AI** project from scratch according to the following specification.

GRAM-AI stands for:

**Agentic Clinical Decision Support System for Rural Community Health Workers Using RAG and Local LLMs**

The system is intended to support ASHA/community health workers in rural India during patient assessment.

IMPORTANT:

* This is a clinical decision-support system, NOT a doctor replacement.
* Never present the system as providing a definitive medical diagnosis.
* Never fabricate medical information, datasets, evaluation metrics, citations, or clinical results.
* Clinical safety must take priority over visual design.
* The final architecture must support offline/local deployment using Ollama + Phi-3 Mini.
* Replit may be used for development/demo, but the final system must be capable of running locally without cloud AI APIs.

7. DIAGNOSIS AGENT
==================

The Diagnosis Agent should combine:

A. Random Forest predictions

AND

B. RAG-grounded Phi-3 Mini reasoning

The fusion mechanism must be transparent.

Do not invent an arbitrary confidence score and present it as medically validated.

If RF and LLM disagree:

* Clearly represent the disagreement internally
* Reduce confidence where appropriate
* Prefer authoritative protocol evidence
* Avoid overconfident conclusions

Output should use wording such as:

"Possible conditions considered"

rather than:

"You have X disease."

Show:

* Possible conditions
* RF confidence/probability
* Relevant protocol evidence
* Reasoning summary
* Uncertainty

==================================================
8. RED-FLAG SAFETY ENGINE
=========================

This is one of the most important components.

Red-flag detection must be:

* Deterministic
* Rule-based
* Independent of the LLM
* Independent of Random Forest
* Configurable

Examples include:

* Unable to drink/breastfeed
* Convulsions
* Lethargy
* Unconsciousness
* Very fast breathing
* Severe dehydration
* Age-specific danger signs

Store rules in a configuration file where possible.

If a red flag is detected:

NORMAL TRIAGE MUST NOT OVERRIDE IT.

The system must clearly display an urgent warning.

Example:

⚠ URGENT REFERRAL

Danger sign detected:
Convulsions

Recommended action:
Immediate referral to an appropriate higher-level health facility.

Do not make the interface frightening unnecessarily, but make emergency information impossible to miss.
